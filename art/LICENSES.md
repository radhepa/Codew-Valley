# Art licences

Every model in `public/models/` was made from scratch for Python Village by the Blender
Python scripts in `art/scripts/` (primitives, lathes and sweeps built with `bmesh`).

No third-party or pre-made assets are used: no KayKit, Quaternius, Kenney or other packs,
no textures, no fonts. If a pre-made CC0 asset is ever added, list it here with its source
URL and licence.
